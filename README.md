# stock-portfolio-tracker
 A web-based Stock Portfolio Tracker designed to help users manage and monitor their stock investments. The application provides portfolio tracking, stock details, investment analysis, profit and loss monitoring, and an easy-to-use interface for managing financial data.# Stock Portfolio Tracker

A Python-based Stock Portfolio Tracker designed to help users manage and monitor their stock investments easily.

## Features

Track stock investments

Monitor portfolio value

Analyze investment performance

Store and manage stock details

Calculate profit and loss

View portfolio information easily

Simple and user-friendly interface

## Technologies Used

Python

Python Data Structures

Financial Data and Calculations

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/Gshivamani49/stock-portfolio-tracker.git
```

2. Open the project folder:

```bash
cd stock-portfolio-tracker
```

3. Run the Python program:

```bash
python "stock portfolio tracker.py"
```
