# Stock Portfolio Tracker

A Python-based Stock Portfolio Tracker designed to help users manage and monitor their stock investments easily.

## Features

* Track stock investments
* Monitor portfolio value
* Analyze investment performance
* Store and manage stock details
* Calculate profit and loss
* View portfolio information easily
* Simple and user-friendly interface

## Technologies Used

* Python
* Python Data Structures
* Financial Data and Calculations

## How to Run

1. Clone the repository
2. Open the project folder
3. Run the Python program

```bash
python "stock portfolio tracker.py"
```

## Project Structure

* README.md
* stock portfolio tracker.py

## Objective

The main objective of this project is to provide a simple and efficient way to manage stock investments, track portfolio performance, and understand investment profits and losses.
